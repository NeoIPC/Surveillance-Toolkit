// source into. The invariant source is the directory root, so `.` is both the default and what an English
// build uses; a localized build is rendered from doc/protocol/<culture>/ with asciidoctor's --base-dir
// still pointing at doc/protocol, and the build passes the culture name here.
//
// It exists because the definitions, the generated lists and the images are all per-culture while the
// header and the PDF theme are shared, so the two classes cannot share one root. Without it a localized
// build reads either the English definitions or no images, depending which root you pick.
//
// The build always passes this, so the ifndef only fires when the document is rendered by hand.

// the shared file otherwise. So every image target in this document is a plain file name with no culture

// the document at all.
//
// A culture is never named in a target, because po4a extracts a target as a translatable unit and a
// translator asked to turn NeoIPC-Core-Decision-Flow.svg into NeoIPC-Core-Decision-Flow.de.svg has no
// way to know the convention -- and a wrong answer shows the English figure silently, a filename that
// resolves being indistinguishable from the right one.
